Hvad er de to værktøjer
GitHub Copilot
Microsoft / GitHub — IDE Extension
Inline autocomplete og chat direkte i din editor (VS Code, Visual Studio, Rider). Tæt GitHub-integration. Fremragende til det daglige flow: tab-completion, inline forslag, code review på PR'er. Ubegrænsede code completions på betalte planer.
VS / VS Code Inline completion GitHub PR review 32K–128K context GPT-4o / Claude modeller
Claude Code
Anthropic — Terminal Agent
Agentic terminal-assistent der selv læser din codebase, skriver, tester og itererer på tværs af mange filer. Ikke inline autocomplete — derimod opgavebaseret: "refactor dette modul", "skriv tests for hele controlleren", "konvertér Figma-komponent til Blazor".
Terminal / CLI Multi-fil agentic 1M token context MCP integrations Claude Sonnet/Opus

📋 Konkret handlingsplan

Uge 1–2 Slå Copilot Business til for hele holdet. Lav en onboarding-session (30 min) om effektive prompts i C#/.NET-kontekst.
Uge 2–4 Giv Claude Code Pro til 2–3 nøglepersoner: backend-lead (Umbraco-migrationer), frontend-dev (Figma MCP) og API/Blazor-dev. Kør en konkret opgave per person.
Md. 2–3 Evaluer: Hvem bruger Claude Code aktivt? Udvid licenser til dem der viser ROI. Drop de ubrugte. Vurder om Max 5x er nødvendigt for heavy users.
