Copilot skifter til usage-based billing — hvad betyder det?
💡

Kort svar: Seatprisen forbliver kr. 122/bruger/md (Business). Men fra 1. juni 2026 gælder et credit-system, og tunge agentic-brugere kan overskride det inkluderede beløb og betale ekstra. For typiske .NET-udviklere med primært inline completion og chat er risikoen lav. For devs der kører agent mode intensivt, er der reel risiko for mersomkostninger.

Tidslinje
Tidligere (før 1. juni 2026)
Fast pris, unbegrænset: Premium Request Units (PRUs). Ubegrænset inline completion. Begrænsede "premium" requests (chat, agent). Fast månedspris = forudsigeligt.
1. juni 2026 — NU
GitHub AI Credits: PRUs erstattes af AI Credits (1 credit = $0,01). Business inkluderer $19 credits/seat/md. Code completions og Next Edit Suggestions er stadig gratis og ubegrænsede. Alt andet (chat, agent mode, code review) trækker fra creditbudgettet baseret på token-forbrug.
Hvad der ændrer sig
Pooling: For Business-kunder deles credits på tværs af holdet. En udvikler der bruger lidt frigiver credits til den der bruger meget.

Overforbrug: Hvis holdet bruger mere end $19 × antal seats, betales overskridelsen per token. Adminstrationen kan sætte spend-caps per bruger.
Hvad der IKKE ændrer sig
Seatprisen stiger ikke. Code completion forbliver ubegrænset. For et hold der primært bruger Copilot til inline forslag og lejlighedsvis chat, ændres den reelle månedspris sandsynligvis ikke.

Umbraco Backend
Ny content type + controller
GitHub Copilot
Åbn VS Code. Skriv public class — Copilot foreslår hele content type-klassen med IPublishedContent properties.
Tryk Tab for at acceptere. Skriv controller-signaturen — Copilot udfylder UmbracoApiController-boilerplate automatisk.
Brug Copilot Chat: "Add a route for listing these items with pagination" — får komplet implementation inline.
Copilot Chat prompt-eksempel
Add a strongly typed Umbraco 13 surface controller for this content type with TryUpdateModel and redirect-on-success pattern

Umbraco Backend
Migration af 40 content types til ny struktur
Claude Code
Start Claude Code i projektets rodmappe: claude i terminalen. Giv den hele konteksten.
Beskriv opgaven — Claude læser alle relevante filer og laver en plan som du godkender.
Claude opdaterer systematisk alle content types, tests og views. Kører build og retter kompileringsfejl selv.
Du reviewer diffsene i Git — Claude har kørt testene undervejs og sikret at alt passer.
Claude Code prompt-eksempel
Migrate all content types in /src/ContentTypes from Umbraco 10 to Umbraco 13 ModelsBuilder format. Update all associated views and controllers. Run the build and fix any compilation errors. Summarize what changed.

Write comprehensive xUnit tests for all controllers in /src/Api/Controllers. Use Moq for dependencies. Cover happy path, 404, and validation errors. Run the tests and fix any that fail.

Handlingsplan
Uge 1
Copilot Business til alle 5. Opsæt GitHub organisation. Sæt spend-cap til $0 overforbrug (admin console). Hold onboarding-session (30 min) med fokus på C#-prompting og chat-shortcuts.
Uge 2–3
Claude Code Pro til 2–3 nøglepersoner. Hver får en konkret opgave: Umbraco-dev prøver en migration, frontend-dev opsætter Figma MCP, API-dev kører test-generering på en controller. Evaluér hvad der virker.
Md. 2–3
Evaluer og skalér. Hvem bruger Claude Code aktivt? Udvid til de resterende devs hvis de har konkrete use cases. Vurder om nogen skal op på Max 5x (kr. 640/md) hvis de løber tør på Pro.
Løbende
Monitorér Copilot forbrug i GitHub Admin Console (Premium Request Analytics). Tjek om nogen konsekvent overskrider credit-budgettet — overvej om de skal have spend-cap hævet eller skifte workflow.
