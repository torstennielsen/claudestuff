🎯 Executive Summary

Anbefaling: Claude Code Custom Løsning (med Notion som fallback)

Hvad: Markdown-baseret dokumentation hosted på GitHub, synced til en web-UI bygget med Claude Code. Granular access control via Entra ID (M365) for interne + custom API-keys for kunder.

Hvorfor: Maksimal kontrol, Claude-integreret vedligeholdelse, git-driven versionering, ingen dyre SaaS-subscriptions.

Timeline: 4-6 uger til MVP, 2-3 uger til full-blown med customer auth.

Cost: ~3.000 DKK opsætning + minimal løbende (Azure hosting).

If not feasible: Pure Notion med approval-workflows som fallback — 1 uge til setup, ingen code.

⚖️ Sammenligning af 3 Optioner

💡 Option 1: Pure Notion

Setup: Notion workspace med interne sider + shareable links for kunder.

✅ Pros:
  • Simpel UI — folk ved hvordan det virker
  • Relationer, databases, custom views uden code
  • Granular sharing: per-page eller hele workspace
  • Søg & filter built-in
  • Ingen vedligeholdelsesomkostninger
❌ Cons:
  • Ingen git-integration (data låst i Notion)
  • Ingen Claude Code-integrering direkte
  • 2-person editor limit på free plan
  • Entra ID auth kræver Notion Teams (pricey)
  • Hvis du vil ændre senere: migrationsproblem
Hurtigt Låst ind No AI-sync

💬 Option 2: Slack/Teams Canvas + Online Host

Setup: Docs hosted på GitHub Pages / Vercel. Searchable fra Slack/Teams via integration.

✅ Pros:
  • Folk kan spørge "show me X" i Slack → resultat i tråd
  • GitHub-drevet (git history, branches)
  • Let at dele eksternt (bare URL)
  • Billig hosting (free tier mulig)
  • Integrerer med dine workflows allerede
❌ Cons:
  • Slack searchable integration er ikke triviel (custom bot)
  • Entra ID auth kræver ekstra werk
  • Slack search bot kobes/bygges separat
  • Granular per-dokument access: svært
  • Slack/Teams Canvas selv er ikke persistent (messages expire)
Git-native Custom bot nødvendig Billig

⚙️ Option 3: Claude Code Custom (anbefalet)

Setup: Markdown docs på GitHub + Claude Code-webapp med Entra ID auth + customer API-keys.

✅ Pros:
  • Claude hjælper med vedligeholdelse aktivt
  • Git-driven — fuld version history
  • Custom auth (Entra ID + per-customer keys)
  • Granular access control (by section/tag)
  • Søg, relateret indhold, smart features
  • Du ejer koden 100%
  • Kan bygges ud gradualt (MVP → full)
❌ Cons:
  • Kræver 4-6 uger initial build
  • Kræver ongoing vedligeholdelse (selv med Claude)
  • Hvis Claude Code-infrastructure down: læses fra fallback
  • Setup complexity over Notion/Slack
Git-driven AI-integrated Kontrol Setup tid

🚀 Implementation Roadmap (Claude Code)

Fase 1: MVP (2-3 uger)

  • Migrering: Eksportér Tettra til Markdown, push til GitHub repo
  • Web-app: React-baseret docsite med søg + tags
  • Auth: Simple API-key auth til start (kunder)
  • Hosting: Azure Static Web Apps eller Vercel
  • Claude: Prompt til "opdater doc X baseret på Y"

Fase 2: Full (3-4 uger efter MVP)

  • Entra ID: Intern M365-login for team
  • Customer segments: Granular access by customer group
  • Versioning: Git-drevet changelog per doc
  • Smart features: Related docs, Claude-suggested updates
  • Analytics: Track hvilke docs der læses mest

Fase 3: Vedligeholdelse (løbende)

  • Monthly: Claude Code-baseret audit (er docs opdateret?)
  • Sync GitHub + Display: Autodeploy ved push
  • Team prompter: Ulla/Mikkel kan updater docs via Claude chat

🛡️ Fallback Plan: If Claude Code Deemed Risky

Go with Pure Notion instead:
  • Setup: 1-2 timer (template + share links)
  • Cost: 2.000 DKK/år (Notion Teams med SSO)
  • Trade-off: Ingen git, ingen Claude-vedligeholdelse, men stabilt & simpelt
  • Futureboard: Migrate til Claude Code senere uden data-loss (Notion → Markdown export)

❓ Kritiske Follow-up Spørgsmål

1. Vedligeholdelse Ownership

Skal Ulla eller Mikkel have klart ownership, eller må flere folk redigere?

Impact: Påvirker approval workflows & git-branches.

2. Customer Segments

Hvor mange customer-grupper skal kunne se hver sit subset af docs?

Impact: Enkel (1-2 grupper) vs. kompleks (10+).

3. Markdown vs. WYSIWYG

Er team komfortable med at skrive Markdown, eller skal der være visual editor?

Impact: Claude Code kan tilføje WYSIWYG senere, men complexity stiger.

4. Migration Timeline

Kan I holde Tettra aktiv mens I bygger — eller skal det være "cutover"?

Impact: Parallelt drift = sikkert; cutover = presset launch.

📋 Næste Trin

If You're Green-Lighting Claude Code

  1. Export fra Tettra: JSON/PDF → Markdown struktur. (~2 timer manuelt eller custom script)
  2. GitHub setup: Repo strukturering (docs/ folder med tags/categories)
  3. Claude Code kickoff: Jeg starter MVP-prototype (React + search + basic auth)
  4. Week 2-3: You test, iterate, feedback
  5. Week 4-6: Entra ID + customer segments
